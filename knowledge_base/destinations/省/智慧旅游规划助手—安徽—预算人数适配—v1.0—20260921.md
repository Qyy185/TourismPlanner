# 安徽预算与人数适配

本文件是安徽目的地的「参数层」，回答两个问题：同样的路线，**不同预算**怎么调整？**不同人数**有什么差异？

这两个维度不改变路线走向（去哪几个点、玩几天），只改变消费标准与出行组织方式，因此单独成篇，避免与路线内容重复。

---

## 安徽的成本特征（先看这个）

安徽预算结构的关键，三点先理解：

1. **黄山山顶住宿是最大变量**。山下汤口 / 屯溪经济型 200-400 元 / 晚，而**山顶宾馆（光明顶、北海、玉屏楼等）旺季标间 1000-2000+ 元 / 晚、床位 200-400 元**，且需提前数日预订。是否住山顶，直接拉开预算档位。
2. **索道是必算的弹性支出**。黄山四条索道单程约 80-100 元，玉屏 / 云谷往返约 160-200 元 / 人，西海大峡谷观光缆车约 100 元。全程徒步虽省索道费，但需多住一晚 + 体力成本。
3. **古村落门票叠加**。宏村、西递各约 104 元（三日有效可共用），徽州古城联票约 80 元，九华山约 160 元。皖南「山 + 村 + 佛」组合，门票累计约 500-700 元 / 人，是硬成本。

**计算口径**：金额为人均人民币；**含**省内住宿、餐饮、城际交通、市内交通、门票娱乐；**不含**往返安徽的大交通与旅游保险。

## 预算档位对照表

### 档位 1｜人均 500 元（极限穷游 · 1-2 天）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 80-120 元/晚 | 汤口 / 屯溪青旅床位 |
| 餐饮 | 40-60 元/天 | 小吃、面、自带干粮 |
| 交通 | 30-50 元/天 | 公交 + 步行 |
| 门票 | 0-100 元 | 只走免费区：屯溪老街、徽州古城街区 |
| 可行范围 | 单城 1-2 天 | 屯溪 / 合肥周边，不含黄山 |

**要点**：500 元**走不了黄山**（门票 + 索道 + 山下住宿就超）。穷游只能玩免费古街 + 小吃，或合肥三河古镇（免费街区）。想上山需上调到 1000 档。

## 人数适配说明

安徽（尤其黄山）**索道按人计费、山顶住宿按间计费**，人数是影响人均的关键：山顶一间标间住 2 人比住 1 人人均减半，而索道、门票、景交按人不打折。

### 1 人出行

- **住宿**：青旅床位（80-150 元）最经济；中端酒店单间按间计价，独行成本高。**山顶床位（200-400 元）是 solo 看日出最划算方案**。
- **交通**：高铁 + 景交最方便，无需包车。黄山徒步 solo 需注意安全（结伴更好）。
- **餐饮**：徽菜份量偏大，单人点菜浪费，建议小吃 / 民宿含餐 / 分食。
- **安全提示**：黄山徒步**不要独自走未开发区域**，雨季 slippery；九华山徒步 solo 也安全。
- **适合路线**：黄山（山顶床位）、宏村西递、徽州古城。

### 2 人出行 ★

- **住宿**：性价比最优。**山顶标间两人均摊**（旺季 1000-2000+ 元 / 间，人均 500-1000 元），比各自住床位体验好。
- **交通**：高铁二等座两人约 200-400 元 / 程，分摊低；景交索道按人不打折。
- **餐饮**：可点 3-4 个菜，臭鳜鱼、一品锅都能尝。
- **适合路线**：全部路线，默认推荐配置。

### 3 人出行

- **住宿**：**麻烦点**。山顶标间住 3 人挤，方案：① 标间 + 1 床位；② 两间（标间 + 单间）；③ 山下整租民宿（黟县三居 400-700 元 / 晚）。**古村阶段强烈建议整租民宿**。
- **交通**：高铁 3 人票约 300-600 元 / 程；景交索道按人。
- **提示**：黄山阶段 3 人分摊山顶房不划算（房间小），建议 2 人标间 + 1 人床位，或全住山下。

### 4 人出行 ★

- **住宿**：两间标间，或古村整套两居 / 三居民宿。山顶可开两间标间（4 人均摊可控）。
- **交通**：4 人高铁票约 400-800 元 / 程；黄山景区内以景交 + 索道为主，无需包车。黄山—宏村—九华跨城可包车（约 400-600 元 / 天）人均低。
- **餐饮**：最理想点菜规模，徽菜全席刚好。
- **建议**：4 人跨城移动（黄山—九华）包车比各自高铁 + 接驳更顺。

### 5 人出行

- **住宿**：两间房（三人间 + 标间）或整套民宿。5 人以上直接找「可住 5-6 人」的徽派院落。
- **交通**：需 7 座商务车（跨城约 500-700 元 / 天），人均仍低。
- **餐饮**：可订桌吃徽菜全席、一品锅。
- **提示**：5 人是「包车 + 整租」的性价比拐点。

### 10 人出行

- **住宿**：**整栋徽派院落 / 古村客栈最划算**。宏村、西递、呈坎有大量可住 10-15 人的老宅院落，整租约 1500-3000 元 / 晚，人均 150-300 元。
- **交通**：**包中巴（19 座）约 1000-1500 元 / 天**，人均 100-150 元 / 天；黄山景区内仍靠景交。
- **门票**：10 人以上可询问团体票（部分景区支持，如黄山、九华）。
- **组织建议**：黄山山顶房紧张，**10 人务必提前数日统一订床位 / 标间**，否则分住山下打乱看日出计划。古村、九华需统一集合。
- **注意**：黄山徒步路段窄、台阶多，10 人需控制队形、防走散；老人小孩关注体力，勿按最强者节奏。

## 预算与人数组合速查

| 人数 \ 预算 | 500 | 1000 | 2000 | 3000 | 5000 | 8000 | 10000 |
|---|---|---|---|---|---|---|---|
| **1 人** | 青旅 + 免费区 | 经济单间 + 黄山日游 | 山下单间 + 索道 | 山顶床位 + 古村 | 山顶标间 + 九华 | 度假村 | 顶奢套房 |
| **2 人** | 床位 ×2 | 经济标间 + 黄山 | 中端标间 + 宏村 | 山顶标间 + 古村 | 山顶标间 + 九华 | 徽派度假村 | 私汤独栋 |
| **3 人** | 青旅三人间 | 整套民宿 | 三居民宿 + 索道 | 山顶房 + 古村民宿 | 古村三居 + 九华 | 度假村套间 | 顶奢别墅 |
| **4 人** | 两间青旅 | 整套民宿 | 四居民宿 + 索道 | 山顶两标间 + 古村 | 古村四居 + 九华 | 度假村 | 私人院落 |
| **5 人** | 整租民宿 | 整租 + 高铁 | 整租 + 7 座 | 品质整租 + 7 座 | 高端整院 + 九华 | 度假村多间 | 别墅整栋 |
| **10 人** | 整栋院落 | 整栋 + 中巴 | 整栋 + 中巴 | 品质整栋 + 中巴 | 高端整栋 | 度假村包区 | 私人庄园 |

> 表中「500 / 1000 / …」指人均预算档位（元）。安徽的组合规律是：**黄山山顶住宿是预算分水岭**——1-2 人住山顶床位控成本，2 人及以上可分摊标间；想稳看日出云海，请预留 3000 档及以上的山顶房预算。另需注意：**旺季（3-11 月，尤其五一、十一、暑期）山顶房与山下住宿全面溢价**，上表为平季参考，旺季请整体上调。
