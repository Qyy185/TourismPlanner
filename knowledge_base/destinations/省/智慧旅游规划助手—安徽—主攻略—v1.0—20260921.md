# 安徽旅游攻略

## 城市概览

安徽，简称「皖」，省会合肥，地跨江淮，北接中原、南邻江南。皖南（黄山、宣城、池州）是安徽旅游的核心——黄山、九华山、徽州古村落构成「名山 + 佛教圣地 + 徽文化」的黄金三角；皖中（合肥、安庆）有天柱山、三河古镇；皖北相对文旅弱。安徽最具辨识度的是**徽文化**：粉墙黛瓦的马头墙、徽派古村落（宏村、西递）、徽菜（臭鳜鱼、毛豆腐、一品锅）与徽商历史。气候为亚热带季风，山区（黄山、九华、天柱）垂直差异大，**黄山山顶与山下温差常达 10℃ 以上**，登山需分层穿衣。

- **最佳旅行季节**：3-5 月（春花、云海概率高）、9-11 月（秋高气爽、红叶）。避开 7-8 月盛夏高温与梅雨季（6 月下旬—7 月上旬）、冬季冰雪封道（部分山峰）。
- **建议游玩天数**：黄山单山 2 天；黄山 + 宏村 / 西递 3-4 天；加九华山 / 徽州古城为 5-7 天。
- **人均预算参考**：2500-4500 元（5 天，不含往返大交通）。**黄山山上住宿昂贵**是最大变量。
- **行政区类别**：省。**省会**：合肥。**主要旅行城市**：黄山（屯溪）、池州（九华）、安庆（天柱山）、宣城、合肥。
- **关键词**：黄山、徽派古村、宏村、九华山、徽菜、天柱山。

## 热门景点

### 黄山风景区（黄山市）

世界文化与自然双遗产，以「奇松、怪石、云海、温泉、冬雪」五绝闻名。主峰莲花峰海拔 1864 米。景区分**前山**（南大门慈光阁进，经玉屏楼看迎客松、天都峰 / 莲花峰，陡峭险峻、景点经典集中）与**后山**（云谷寺进，经白鹅岭、始信峰、狮子峰、西海大峡谷，相对平缓、视野开阔）。天都峰与莲花峰**每 5 年轮流封闭养护**，出行前查官方当日开放信息。

- **门票**：旺季（3-11 月）约 190 元、淡季约 150 元；以官方为准
- **开放时间**：平日 6:30—17:00（季节性调整，冬季更短）
- **建议游玩**：1-2 天（住山上可观日出云海）
- **交通**：高铁「黄山北」站乘景区巴士约 1 小时至汤口（南大门）；或自驾至汤口
- **索道**：**玉屏索道**（前山，慈光阁—玉屏楼）、**云谷索道**（后山，云谷寺—白鹅岭）、**太平索道**（北门松谷庵—丹霞峰）、**西海大峡谷观光缆车**（排云溪—天海，下行体验「网红小火车」）
- **实用建议**：**普通游客建议索道上下 + 徒步精华**，全程徒步约 22 公里、爬升大，一日强度极高。经典走法：后山云谷索道上 → 始信峰 → 光明顶 → 前山玉屏索道下（迎客松）。**日出观景点**：光明顶（最经典、开阔）、狮子峰清凉台、丹霞峰、始信峰、鳌鱼峰。**山顶住宿贵且需提前订**，想看日出云海务必早约。莲花峰 / 天都峰轮换开放，登顶前确认。山区天气多变，备雨衣与防风外套。

### 宏村（黄山市黟县）

世界文化遗产，徽派古村落代表，以「牛形村落」布局、月沼与南湖倒影闻名，粉墙黛瓦马头墙是中国水墨画的现实版。

- **门票**：约 104 元（三日有效）；以官方为准
- **开放时间**：全天（村落）；宅院约 8:00—17:30
- **建议游玩**：半天至 1 天（住一晚看晨雾最佳）
- **交通**：黄山北站乘巴士约 1.5 小时，或自驾；黟县转公交
- **实用建议**：**清晨（7 点前）与傍晚人少、南湖水面如镜最出片**。月沼、南湖、承志堂必看。住村内民宿体验徽派老宅。避免正午旅游团高峰。

### 西递（黄山市黟县）

与宏村齐名的徽派古村落世界遗产，以胡氏宗祠、牌坊群与保存完整的明清民居著称，比宏村更「原真」、商业味略淡。

- **门票**：约 104 元（三日有效）；以官方为准
- **开放时间**：全天（村落）；宅院约 8:00—17:30
- **建议游玩**：半天
- **交通**：黟县乘公交 / 打车约 20 分钟；宏村—西递约 30 分钟
- **实用提示**：宏村看「水」与倒影，西递看「牌坊与民居」，两者风格互补，可同半天串游（相距约 20 公里）。胡文光牌坊、敬爱堂是核心。

### 九华山（池州市青阳县）

中国佛教四大名山之一，地藏菩萨道场，以寺庙群（化城寺、肉身宝殿、百岁宫）、奇峰与香火闻名，兼具朝圣与观光。

- **门票**：约 160 元（旺季），景交车另计；以官方为准
- **开放时间**：6:30—17:30（季节性）
- **建议游玩**：1-2 天
- **交通**：高铁「九华山」站（池黄高铁）或「池州」站转巴士；自驾至柯村（南大门）
- **实用建议**：九华街（山上核心寺院区）需乘景交车上山。肉身宝殿、百岁宫（缆车可达）是朝圣重点。香客多，尊重宗教习俗（不喧哗、不穿短裙入殿）。与黄山相距约 2 小时车程，可黄九连线。

### 天柱山（安庆市潜山市）

安徽三大名山之一（与黄山、九华并列），主峰天柱峰海拔 1489 米，以「雄、奇、灵、秀」的花岗岩峰林著称，世界地质公园。

- **门票**：约 130 元（旺季），索道另计；以官方为准
- **开放时间**：7:00—17:30
- **建议游玩**：1 天
- **交通**：高铁「潜山」站转巴士约 40 分钟；或自驾
- **实用提示**：大龙窝索道可省体力。炼丹湖、神秘谷、天柱峰是核心。比黄山人少、性价比高，适合避开黄山人潮的替代。

### 三河古镇（合肥市肥西县）

巢湖之滨的水乡古镇，因丰乐河、杭埠河、小南河三水流贯而得名，明清古街、古桥、徽派与淮军文化交融。

- **门票**：街区免费；部分宅院（杨振宁旧居、刘同兴隆庄）联票约 50 元；以官方为准
- **开放时间**：全天（街区）；宅院约 8:00—17:30
- **建议游玩**：半天
- **交通**：合肥市区自驾 / 巴士约 1 小时；或高铁肥西转乘
- **实用提示**：距合肥近，适合作为合肥中转半日游。美食（三河米饺）值得尝。比皖南水乡商业化轻。

### 徽州古城（黄山市歙县）

中国四大古城之一（与丽江、平遥、阆中并列），徽州府治所在，含许国石坊（八脚牌坊）、徽州府衙、斗山街、渔梁坝等，是徽文化腹地。

- **门票**：古城街区免费；府衙等联票约 80 元；以官方为准
- **开放时间**：全天（街区）；衙署约 8:00—17:30
- **建议游玩**：半天
- **交通**：黄山北站乘巴士约 40 分钟；歙县北站打车约 15 分钟
- **实用提示**：许国石坊是全国罕见的八脚牌坊，必看；渔梁坝是古老水利工程的代表。可与棠樾牌坊群、呈坎顺路。

### 屯溪老街（黄山市屯溪区）

黄山脚下（黄山北站所在区）的千年商业街，徽派建筑格局完整，是进出黄山的补给与美食据点。

- **门票**：免费
- **开放时间**：全天（店铺约 9:00—21:00）
- **建议游玩**：2-3 小时
- **交通**：黄山北站打车约 15 分钟；或公交
- **实用建议**：出发登黄山前在此采买干粮、雨衣、登山杖。老街一马路小吃（徽州毛豆腐、挞粿）可先尝徽味。比景区内便宜。

### 呈坎（黄山市徽州区）

按八卦布局的「江南第一村」，明清古建保存极好，罗东舒祠被誉为「江南第一名祠」，比宏村西递更安静。

- **门票**：约 107 元；以官方为准
- **开放时间**：7:30—17:30
- **建议游玩**：2-3 小时
- **交通**：黄山北站自驾 / 巴士约 30 分钟
- **实用提示**：「游呈坎，一生无坎」的民俗说法。古建爱好者的宝藏，可与徽州古城同半日。

## 特色美食

### 徽菜代表（必尝）

- **臭鳜鱼**——徽菜招牌，腌鲜鳜鱼微臭实香、肉质蒜瓣状，红烧最佳
- **毛豆腐**——发酵豆腐表面长绒毛，油煎蘸辣酱，闻着臭吃着香
- **一品锅**——胡适一品锅 / 绩溪一品锅，分层码放肉圆、蛋饺、笋干、豆腐等炖成一锅，徽州待客大菜
- **刀板香**——腌腊肉切薄片，咸香下饭
- **问政山笋**——徽州春笋名品，嫩鲜清甜

### 皖南小吃

- **挞粿**——徽州煎饼，馅料多样，老街常见
- **徽州毛峰（茶）**——绿茶名品，黄山特产
- **笋干烧肉**——家常徽菜
- **石头粿**——徽州特色馅饼

### 合肥 / 皖中

- **庐州烤鸭**、**三河米饺**——合肥与三河代表
- **小龙虾**（合肥夜市夏季）

**觅食提示**：徽菜整体偏咸鲜、重火工，臭鳜鱼与毛豆腐是风味门槛，初次可小份尝试。屯溪老街、宏村村内餐厅价格高于村外，点菜前问价。山区（黄山）餐饮贵且选择少，**上山前在屯溪备好干粮与水**。

## 住宿建议

### 黄山脚下（汤口 / 屯溪）

- **汤口（南大门）**：登山前夜住宿，经济型 200-400 元 / 晚，方便早进山
- **屯溪（黄山北站）**：补给与美食据点，中端 250-500 元 / 晚

### 黄山山上

- **光明顶 / 北海 / 白鹅岭一带宾馆**（如白云、北海、玉屏楼）：**价格昂贵，标间旺季 1000-2000+ 元 / 晚，床位 200-400 元**，且需提前数日预订。**想看日出云海必住山上**，否则需夜爬或早起赶索道

### 黟县（宏村 / 西递）

- **村内徽派民宿**：体验老宅，300-800 元 / 晚；节假日溢价明显
- **黟县县城 / 外围**：便宜 150-300 元 / 晚，自驾 20 分钟进景区

### 九华山 / 天柱山 / 合肥

- 九华街周边寺院区住宿 300-700 元 / 晚；天柱山脚下 200-500 元 / 晚；合肥市区 250-500 元 / 晚。

## 交通指南

### 大交通

- **高铁**：黄山北站（合福 + 杭黄高铁）通达合肥、杭州、南昌、福州；池黄高铁通九华山、黄山西；合肥是全省枢纽（商合杭、合福、合武）。
- **航空**：合肥新桥国际机场为主；黄山屯溪机场为支线。
- **公路**：皖南山区高速（杭瑞、京台）发达，但景区连接线多山路。

### 省内交通

- **城际**：优先高铁。黄山北—合肥南约 1.5-2 小时；黄山北—九华山（池黄）约 1 小时。
- **景区接驳**：黄山汤口、九华街、天柱山均需「高铁站—景区」巴士 / 景交车，提前查班次。
- **市内 / 村内**：古村落内步行；徽州古城、屯溪老街步行即可。

## 注意事项

- **黄山登山强度**：黄山全程徒步约 22 公里、累计爬升大，**普通游客务必索道上下 + 徒步精华**，不要逞强全程徒步。天都峰 / 莲花峰险峻，恐高、心脏病者慎登。山上台阶湿滑，穿防滑鞋、备登山杖。
- **山顶温差与天气**：山顶与山下温差常 10℃+，山顶风大、天气多变，**即使夏季也带防风外套与雨衣**（山上禁打伞防雷）。冬季部分路段结冰封道，关注官方公告。
- **山上住宿贵且紧**：光明顶 / 北海等宾馆旺季 1000-2000+ 元 / 晚，需提前数日订；想看日出云海务必早约，否则只能山下早起赶首班索道（仍可能错过最佳光线）。
- **徽州古村预约**：宏村、西递、徽州古城旺季限流，**提前购票**，节假日车位紧张，建议公共交通进山。
- **宗教习俗（九华山）**：入殿不喧哗、不穿短裙短裤、不随意拍摄佛像与僧人，尊重香客。
- **梅雨与盛夏**：6 月下旬—7 月上旬梅雨山路湿滑、云海虽多但视野差；7-8 月皖南闷热，登山注意防暑补水。
- **消费避坑**：黄山山下「低价一日游」、景区周边「野导」风险高，认准官方平台与景交；购物（茶叶、徽墨）到正规店要发票。
