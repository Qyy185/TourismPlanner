# 河北预算与人数适配

本文件是河北目的地的「参数层」，回答两个问题：同样的路线，**不同预算**怎么调整？**不同人数**有什么差异？

河北的成本特征与天津、上海不同，有三点必须先理解：

1. **城际交通占比中等偏高**。石家庄—承德、—秦皇岛的高铁 1-3 小时，承德—坝上还需 3-4 小时车程。这部分省不下来，只能提前购票。
2. **景区门票单价中等**。避暑山庄约 130 元、白石山约 135 元、坝上/塞罕坝约 130 元，属于硬成本，但多数古建（正定）免费。
3. **包车是最大弹性支出**。坝上、白石山、野三坡、清东岭**无公共交通覆盖**，必须包车（河北 5 座约 500-800 元/天，7 座约 700-1000 元/天）。**人数越多，人均越低**——这是河北预算优化最大的杠杆。

## 预算档位对照表

**计算口径**：

- 金额均为**人均**，单位为人民币
- **含**：省内住宿、餐饮、城际交通、市内/景区交通、门票与娱乐
- **不含**：往返河北的大交通（机票/跨省市高铁）、旅游保险、大额购物
- 天数为参考天数；实际天数不同时按日均值折算

### 档位 1｜人均 500 元（极限穷游 · 1-2 天）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 60-100 元/晚 | 青旅床位或经济连锁特价，推荐石家庄/保定/唐山地铁或车站周边 |
| 餐饮 | 40-60 元/天 | 驴肉火烧、面馆、便民食堂 |
| 交通 | 30-50 元/天 | 高铁二等座 + 市内公交，不包车 |
| 门票 | 0-50 元 | 只走免费区：正定古城（隆兴寺除外）、石家庄博物院 |
| 可行路线 | 单城 1-2 天 | 正定 + 石家庄，或北戴河海滩漫步（非暑期） |

**要点**：河北能穷游，但**只限「有免费古建的城市」**——正定是全省性价比之王（四塔免费、隆兴寺仅约 50 元）。坝上、白石山本档放弃（包车成本不合算）。

### 档位 2｜人均 1000 元（经济自助 · 2-3 天）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 120-200 元/晚 | 经济连锁或青旅单间 |
| 餐饮 | 80-120 元/天 | 本地小馆 + 1 顿正餐 |
| 交通 | 100-150 元/天 | 高铁 + 市内公交，偶尔拼车 |
| 门票 | 100-200 元 | 选 1-2 个付费点（避暑山庄或白石山） |
| 可行路线 | 正定 + 承德/保定 3 天 | 走 3 日主线的精简版，不去坝上 |

**要点**：动车票提前买，石家庄—承德/秦皇岛二等座需抢折扣。本档可舒服逛完「正定 + 一地」，坝上仍需更高预算。

### 档位 3｜人均 2000 元（舒适自助 · 3 天）★

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 250-400 元/晚 | 中端酒店，承德/北戴河/石家庄市区 |
| 餐饮 | 130-180 元/天 | 口碑餐厅为主 |
| 交通 | 150-250 元/天 | 高铁 + 景区拼车，出行不将就 |
| 门票 | 200-350 元 | 可含 2-3 个付费景点 |
| 可行路线 | 承德 3 日或正定+保定 3 日 | 山庄 + 外八庙 + 金山岭 |

**要点**：这是**短假期的舒适区间**。3 天建议只攻一个区域（承德或秦皇岛），跨区域会赶路。承德住市区最方便。

### 档位 4｜人均 3000 元（品质游 · 5 天）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 400-700 元/晚 | 四星或景区周边品质酒店 |
| 餐饮 | 250-350 元/天 | 特色餐厅 + 1-2 顿名店 |
| 交通 | 250-400 元/天 | 高铁 + 区域包车（承德/秦皇岛接驳） |
| 门票 | 500-800 元 | 含避暑山庄、外八庙、山海关、白石山等 |
| 可行路线 | 承德 + 秦皇岛 5 日主线 | 完整走完皇家园林 + 海滨 |

**要点**：**河北 5 日线的标准预算**。这档能走完「承德 + 海滨」主线，住得舒服、包车不心疼。注意暑期北戴河房价翻倍，本档建议避开 7 月下旬-8 月上旬。

### 档位 5｜人均 5000 元（深度品质 · 5-7 天）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 800-1200 元/晚 | 景区品质酒店、草原度假村 |
| 餐饮 | 400-550 元/天 | 好餐厅为主，含草原/海鲜大餐 |
| 交通 | 400-700 元/天 | 全程包车 + 高铁衔接 |
| 门票 | 800 元以上 | 全含，含坝上、金山岭缆车等 |
| 可行路线 | 7 日跨区域环线（中北线） | 正定 + 太行 + 承德 + 坝上 |

**要点**：到这一档可走「中北环线」并加入坝上。坝上建议住有供暖/暖气的度假村（秋季夜间冷）。草原段必须包车。

### 档位 6｜人均 8000 元（高端精品 · 7 天）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 1500-2500 元/晚 | 山庄/海滨/草原高端度假酒店 |
| 餐饮 | 600-800 元/天 | 高端餐厅、定制餐 |
| 交通 | 700 元/天 | 专车 + 司机，机场接送 |
| 门票体验 | 不限 | 含 VIP 通道、私享导览 |

**要点**：河北高端住宿有独特性——承德山庄旁精品、北戴河海景、坝上草原木屋，各有不可替代性。

### 档位 7｜人均 10000 元以上（奢华定制）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 3000 元/晚以上 | 顶奢度假村套房、草原私墅 |
| 餐饮 | 1000 元/天以上 | 主厨定制、包场用餐 |
| 交通 | 不限 | 豪华专车、直升机观光（坝上/长城） |
| 特色体验 | 不限 | 私人向导、长城包场日出、草原那达慕定制 |

**要点**：这一档买的是「时间与视角」——例如金山岭包场日出、坝上晨雾私导，普通游客难以获得。

## 人数适配说明

河北的**包车成本**使人数成为影响人均预算的关键变量，这一点在坝上、太行线尤为明显。

### 1 人出行

- **住宿**：青旅床位（60-120 元）或经济连锁单间（150-250 元）最经济。
- **交通**：**包车极不划算**（一人承担全车费）。建议：① 高铁 + 公交完成主要移动；② 在正规平台拼车游坝上/白石山；③ 参加一日游团。
- **餐饮**：小吃、面馆、火烧为主，点菜型餐厅不友好。
- **安全提示**：坝上、野三坡等山区**不要独自走未开发路线**，结伴或请向导。
- **适合路线**：正定 + 石家庄、承德市区、北戴河海滨。

### 2 人出行 ★

- **住宿**：性价比最优，标准间/大床房均摊后品质预算减半。
- **交通**：可以拼车，人均摊薄。承德—金山岭、北戴河—山海关两人均摊包车（约 300-400 元/天）比各自坐车更自由。
- **餐饮**：可以点 3-4 个菜，冀菜份量大正好。
- **适合路线**：全部路线，默认推荐配置。

### 3 人出行

- **住宿**：**麻烦点**。河北景区酒店多为标间/大床房，三人间少。方案：① 家庭房（提前确认）；② 加床（常加价 50-100 元）；③ 大床 + 单间；④ **民宿三居**（承德、北戴河、坝上很多，三居 400-800 元/晚，人均最低）。
- **交通**：包车开始明显划算，三人均摊接近公共交通成本。
- **提示**：河北民宿资源丰富，**3 人强烈建议直接订整套民宿**。

### 4 人出行 ★

- **住宿**：两间标间，或整套两居/三居民宿。
- **交通**：**河北最适合的人数**——一辆轿车/SUV 刚好坐 4 人，包车费用最低档（500-700 元/天），人均 125-175 元/天，比任何公共交通组合都自由。
- **餐饮**：最理想点菜规模。
- **建议**：4 人包车去坝上/太行，人均成本最优，强烈推荐。

### 5 人出行

- **住宿**：两间房（三人间 + 标间）或整套民宿。5 人以上直接找「可住 5-6 人」的民宿。
- **交通**：需 **7 座商务车**（约 700-1000 元/天），人均 140-200 元/天，仍比 1-2 人包车划算。
- **餐饮**：可订桌吃正式的承德八大碗、白洋淀全鱼宴。
- **提示**：5 人是「包车 + 整租」的性价比拐点。

### 10 人出行

- **住宿**：**整栋民宿/度假村最划算**。坝上、北戴河、承德有大量可住 10-15 人的院落，整租约 1500-3000 元/晚，人均 150-300 元。
- **交通**：**包中巴（19 座）约 1000-1500 元/天**，人均 100-150 元/天，最优。
- **门票**：10 人以上可询问团体票（部分景区支持）。
- **组织建议**：河北景点分散、车程长，10 人务必提前确认集合时间地点。坝上/长城需关注队内是否有不适者，按最弱者节奏走。
- **注意**：暑期北戴河 10 人订房极难，至少提前 2-3 周；坝上草原住宿秋季紧俏，同样需早订。

## 预算与人数组合速查

| 人数 \ 预算 | 500 | 1000 | 2000 | 3000 | 5000 | 8000 | 10000 |
|---|---|---|---|---|---|---|---|
| **1 人** | 青旅床位 + 正定 | 青旅单间 + 高铁 | 经济单间 + 拼车 | 品质单间 + 一日游 | 度假酒店 | 高端度假村 | 顶奢套房 |
| **2 人** | 床位 ×2 | 经济标间 | 中端标间（舒适） | 四星 + 区域包车 | 高端酒店 | 草原/海景房 | 私人院落 |
| **3 人** | 青旅三人间 | 整套民宿 | 三居民宿 + 拼车 | 品质民宿 + 包车 | 高端整租 | 度假村套间 | 顶奢别墅 |
| **4 人** | 两间青旅 | 整套民宿 | 四居民宿 + 包车 | 品质民宿 + 全程包车 | 高端整租 | 度假村 | 私人院落 |
| **5 人** | 整租民宿 | 整租 + 拼车 | 整租 + 7 座 | 品质整租 + 7 座 | 高端整租 | 度假村多间 | 别墅整栋 |
| **10 人** | 整栋院落 | 整栋 + 中巴 | 整栋 + 中巴 | 品质整栋 + 中巴 | 高端整栋 | 度假村包区 | 私人庄园 |

> 表中「500 / 1000 / …」指人均预算档位（元）。河北的组合规律：**景点分散 + 必须包车，人数越多「包车 + 整租」优势越明显**；1-2 人去坝上/太行优先拼车或一日游团，避免独自承担车费。
