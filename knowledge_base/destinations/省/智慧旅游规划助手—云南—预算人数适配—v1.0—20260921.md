# 云南预算与人数适配

本文件是云南目的地的「参数层」，回答两个问题：同样的路线，**不同预算**怎么调整？**不同人数**有什么差异？

---

## 云南的成本特征（先看这个）

云南的预算结构和其他目的地不同，有三点必须先理解：

1. **城际交通占比高**。昆明—大理—丽江的动车票、飞香格里拉/西双版纳的机票，往往占总预算的 25%-35%。这部分**省不下来**，只能提前买票抢折扣。
2. **景区门票单价高**。玉龙雪山（进山费 + 大索道 + 环保车）合计约 240 元以上，普达措约 258 元，这类支出是硬成本。
3. **包车是最大的弹性支出**。环洱海、进雨崩、上雪山都依赖包车（400-800 元/天）。包车费用按车计价，**人数越多，人均越低**——这是云南预算优化最大的杠杆。

**计算口径**：金额为人均人民币；**含**省内住宿、餐饮、城际交通、市内交通、门票娱乐；**不含**往返云南的大交通与旅游保险。

## 预算档位对照表

### 档位 1｜人均 500 元（极限穷游 · 1-2 天）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 50-80 元/晚 | 昆明/大理青旅多人间床位 |
| 餐饮 | 40-60 元/天 | 小锅米线、烧饵块、市场小吃为主 |
| 交通 | 30-50 元/天 | 全程公交 + 步行，不包车 |
| 门票 | 0 元 | 只走免费区：大理古城、洱海生态廊道（骑行租车另计）、翠湖公园 |
| 可行范围 | 单城 1-2 天 | 昆明或大理一地 |

**要点**：云南确实能穷游，但**建议只用在大理**——洱海生态廊道免费、古城免费、骑行成本极低，500 元能玩得很舒服。昆明免费景点质量不如大理。

### 档位 2｜人均 1000 元（经济自助 · 2-3 天）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 100-180 元/晚 | 青旅单间或经济型客栈 |
| 餐饮 | 80-120 元/天 | 本地小馆 + 1 顿正经馆子 |
| 交通 | 100-150 元/天 | 动车二等座 + 市内公交，偶尔拼车 |
| 门票 | 100-200 元 | 选 1 个付费景点（如崇圣寺三塔或石林） |
| 可行范围 | 昆明 + 大理 3 天 | 走 3 日主线的精简版 |

**要点**：动车票要提前买，昆明—大理二等座约 145 元，临时买容易只剩无座或高价票。

### 档位 3｜人均 2000 元（舒适自助 · 3 天）★

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 200-350 元/晚 | 中端客栈或精品民宿（大理可选海景房） |
| 餐饮 | 130-180 元/天 | 本地口碑餐厅为主 |
| 交通 | 150-250 元/天 | 动车 + 环湖包车拼车，出行不将就 |
| 门票 | 200-350 元 | 可含 2-3 个付费景点 |
| 可行范围 | 昆明 + 大理，或大理 + 丽江 3 天 | |

**要点**：这是**短假期的舒适区间**。3 天建议只走「昆明+大理」或「大理+丽江」，两地之间动车 2 小时，节奏刚好。大理住洱海边（才村/龙龛）是这一档最值的溢价。

### 档位 4｜人均 3000 元（品质游 · 5 天）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 400-700 元/晚 | 精品民宿、海景房、古城边缘品质客栈 |
| 餐饮 | 250-350 元/天 | 特色餐厅 + 1-2 顿名店 |
| 交通 | 250-400 元/天 | 包车为主（环洱海、上雪山），动车衔接 |
| 门票 | 500-800 元 | 含玉龙雪山（索道）、崇圣寺三塔等 |
| 可行范围 | 昆明—大理—丽江 5 日主线 | |

**要点**：**云南 5 日线的标准预算**。这一档能走完整的昆大丽主线，住得舒服、包车不心疼。注意玉龙雪山单日成本约 400 元（门票+索道+车），要预留在内。

### 档位 5｜人均 5000 元（深度品质 · 5-7 天）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 800-1200 元/晚 | 高端海景民宿、度假酒店 |
| 餐饮 | 400-550 元/天 | 好餐厅为主，可含一次高端菌子宴 |
| 交通 | 400-600 元/天 | 全程包车 + 省内机票 |
| 门票 | 800 元以上 | 全含，含高海拔项目 |
| 可行范围 | 昆大丽 + 香格里拉 7 日线 | |

**要点**：到这一档可以「用机票换时间」——丽江到香格里拉、昆明到西双版纳改用飞机，省下的大半天可用来玩。香格里拉建议住有供暖与供氧的度假酒店。

### 档位 6｜人均 8000 元（高端精品 · 7 天）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 1500-2500 元/晚 | 雪山景观房、藏式精品度假村、顶级海景别墅 |
| 餐饮 | 600-800 元/天 | 高端餐厅、定制餐（野生菌季可定制菌宴） |
| 交通 | 700 元/天 | 专车 + 司机，机场接送 |
| 门票体验 | 不限 | 含 VIP 通道、私享导览、热气球等 |

**要点**：云南的高端住宿有独特性——能看到玉龙雪山的房型、洱海一线海景别墅、香格里拉的藏式度假村，这些在别处替代不了。

### 档位 7｜人均 10000 元以上（奢华定制）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 3000 元/晚以上 | 顶奢度假村套房、私人院落别墅 |
| 餐饮 | 1000 元/天以上 | 主厨定制、包场用餐 |
| 交通 | 不限 | 豪华专车 + 直升机/包机（如昆明—香格里拉） |
| 特色体验 | 不限 | 私人向导、梅里雪山日出专车、普洱茶山私人探访 |

**要点**：这一档买的是「时间与视角」——例如梅里雪山的日照金山需要特定时间与位置，私人向导能大幅提高看到概率。

## 人数适配说明

云南的**包车成本**使人数成为影响人均预算的关键变量，这一点比其他目的地更明显。

### 1 人出行

- **住宿**：青旅床位（50-100 元）或青旅单间（120-200 元）最经济。中端客栈单间按间计价，独行成本高。
- **交通**：**包车不划算**（一人承担全车费）。建议：① 参加正规一日游拼团；② 在客栈或拼车平台找人拼车环洱海；③ 靠动车 + 公交完成主要移动。
- **餐饮**：米线、饵丝、小吃为主，点菜型餐厅不友好。云南小吃丰富，单人反而吃得灵活。
- **安全提示**：整体治安良好，但徒步线路（虎跳峡、雨崩）**绝对不要独自走**，务必结伴或请向导。
- **适合路线**：昆明单城、大理慢游、美食探店线。

### 2 人出行 ★

- **住宿**：性价比最优。标准间/大床房均摊后，同样的品质预算减半。
- **交通**：可以拼车，人均摊薄。环洱海包车（500 元/天）两人均摊 250 元/天，比各自坐公交 + 打车更划算且自由。
- **餐饮**：可以点 3-4 个菜，白族菜、菌子锅都能尝。
- **适合路线**：全部路线，默认推荐配置。

### 3 人出行

- **住宿**：**麻烦点**。云南客栈多为标间/大床房，三人间少。方案：① 家庭房（需提前确认）；② 加床（常加价 50-100 元）；③ 大床房 + 单间（成本上升）；④ **民宿三居室**（大理、丽江很多，三居 400-800 元/晚，人均最低）。
- **交通**：包车开始明显划算，三人均摊后接近公共交通成本。
- **提示**：云南民宿资源丰富，**3 人强烈建议直接订整套民宿**，比订酒店房间便宜且更舒适。

### 4 人出行 ★

- **住宿**：两间标间，或整套两居/三居民宿。
- **交通**：**云南最适合的人数**——一辆普通轿车/SUV 刚好坐下 4 人，包车费用最低档。环洱海、上雪山、进雨崩，4 人包车人均成本最优。
- **餐饮**：最理想的点菜规模。
- **建议**：4 人包车（约 500-700 元/天）人均 125-175 元/天，比任何公共交通组合都划算且自由。

### 5 人出行

- **住宿**：两间房（三人间 + 标间）或整套民宿。5 人以上建议直接找「可住 5-6 人」的民宿。
- **交通**：需 **7 座商务车**（约 700-900 元/天），人均 140-180 元/天，仍比 1-2 人包车划算。
- **餐饮**：可以订桌吃正式的野生菌火锅与白族土八碗。
- **提示**：5 人是「包车 + 整租」的性价比拐点，之后人均成本随人数继续下降。

### 10 人出行

- **住宿**：**整栋民宿最划算**。大理、丽江、喜洲有大量可住 10-15 人的院落，整租约 1500-3000 元/晚，人均 150-300 元，远低于同品质酒店。
- **交通**：**包中巴（19 座）约 1000-1500 元/天**，人均 100-150 元/天，是所有方案中最优。
- **门票**：10 人以上可询问团体票政策（部分景区支持）。
- **组织建议**：云南景点分散、车程长，10 人务必提前确认集合时间与地点。高海拔地区（香格里拉、玉龙雪山）要关注队内是否有身体不适者，不要按最强者节奏走。
- **注意**：玉龙雪山大索道、普达措等热门项目**按人预约**，10 人需统一提前抢票，旺季常出现约不齐的情况，建议留出备选方案。

## 预算与人数组合速查

| 人数 \ 预算 | 500 | 1000 | 2000 | 3000 | 5000 | 8000 | 10000 |
|---|---|---|---|---|---|---|---|
| **1 人** | 青旅床位 + 免费区 | 青旅单间 + 拼团 | 客栈单间 + 动车 | 精品单间 + 一日游 | 海景房 + 拼车 | 度假酒店 | 顶奢套房 |
| **2 人** | 床位 ×2 | 经济客栈标间 | 中端客栈 + 拼车 | 海景房 + 包车 | 高端民宿 | 雪山景房 | 私人院落 |
| **3 人** | 青旅三人间 | 整套民宿 | 三居民宿 + 包车 | 品质民宿 + 包车 | 海景三居 | 度假村套间 | 顶奢别墅 |
| **4 人** | 两间青旅 | 整套民宿 | 四居民宿 + 包车 | 品质民宿 + 全程包车 | 海景四居 | 度假村 | 私人院落 |
| **5 人** | 整租民宿 | 整租 + 拼车 | 整租 + 7 座 | 品质整租 + 7 座 | 高端整租 | 度假村多间 | 别墅整栋 |
| **10 人** | 整栋院落 | 整栋 + 中巴 | 整栋 + 中巴 | 品质整栋 + 中巴 | 高端整栋 | 度假村包区 | 私人庄园 |

> 表中「500 / 1000 / …」指人均预算档位（元）。云南的组合规律是：**人数越多，「包车 + 整租」的优势越明显**；1-2 人则应偏向「动车 + 拼车」，避免独自承担车费。
