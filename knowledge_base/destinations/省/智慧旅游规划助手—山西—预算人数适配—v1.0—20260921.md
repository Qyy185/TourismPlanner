# 山西预算与人数适配

本文件是山西目的地的「参数层」，回答两个问题：同样的路线，**不同预算**怎么调整？**不同人数**有什么差异？

山西的成本特征，有三点必须先理解：

1. **城际交通占比高**。太原—大同高铁约 2 小时、太原—平遥约 30 分钟、太原—临汾约 1.5 小时，跨板块移动耗时且需衔接。**古建多在县城与山地，落地后几乎都要包车或拼车**，这是山西最大的弹性支出。
2. **门票单价中等偏低**。平遥联票约 125 元、云冈约 120 元、五台山进山费约 135 元，整体比一线景区友好；但雁北（应县、悬空寺、恒山）多为分散小票，累加也不少。
3. **包车决定人均效率**。应县木塔、悬空寺、壶口、太行山大峡谷、五台山内部均无便利公交，**包车按车计价，人数越多人均越低**——这是山西预算优化最大的杠杆。

## 预算档位对照表

**计算口径**：

- 金额均为**人均**，单位为人民币
- **含**：省内住宿、餐饮、城际交通、市内/景区交通、门票与娱乐
- **不含**：往返山西的大交通（机票/跨省市高铁）、旅游保险、大额购物
- 天数为参考天数；实际天数不同时按日均值折算

### 档位 1｜人均 500 元（极限穷游 · 1-2 天）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 60-100 元/晚 | 青旅床位或经济连锁特价，推荐太原/平遥/大同车站周边 |
| 餐饮 | 35-55 元/天 | 面食为主（刀削面、剔尖），小吃填腹 |
| 交通 | 30-50 元/天 | 高铁二等座 + 公交，不包车 |
| 门票 | 0-50 元 | 只走免费/低价区：平遥古城（进城免费）、晋祠外园、部分寺庙外观 |
| 可行路线 | 单城 1-2 天 | 太原（晋祠外园 + 食品街）或平遥古城漫步 |

**要点**：山西能穷游，关键在于**平遥进城免费、面食便宜**。本档放弃雁北（包车成本高）与需门票的石窟寺院，专注免费古城与街头面食。

### 档位 2｜人均 1000 元（经济自助 · 2-3 天）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 120-200 元/晚 | 经济连锁或青旅单间 |
| 餐饮 | 70-100 元/天 | 本地面馆 + 1 顿正餐 |
| 交通 | 100-150 元/天 | 高铁 + 市内公交，偶尔拼车 |
| 门票 | 100-200 元 | 选 1-2 个付费点（平遥联票或云冈） |
| 可行路线 | 晋中 3 天 | 太原 + 平遥 + 乔家，走 3 日主线精简版 |

**要点**：动车票提前买，太原—平遥二等座便宜。本档可舒服逛完晋中环线，雁北仍建议留给更高预算（需包车）。

### 档位 3｜人均 2000 元（舒适自助 · 3 天）★

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 250-400 元/晚 | 中端酒店，平遥古城客栈/太原市区 |
| 餐饮 | 120-170 元/天 | 口碑面食馆 + 晋菜馆 |
| 交通 | 150-250 元/天 | 高铁 + 景区拼车 |
| 门票 | 200-350 元 | 可含 2-3 个付费景点（联票 + 云冈） |
| 可行路线 | 晋中 3 日主线 | 太原 + 平遥 + 大院，完整覆盖 |

**要点**：这是**短假期的舒适区间**。3 天只攻晋中（太原+平遥+大院）最顺，跨到雁北会赶路。平遥住古城内体验好，但拖行李不便。

### 档位 4｜人均 3000 元（品质游 · 5 天）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 400-700 元/晚 | 四星或古城品质客栈 |
| 餐饮 | 250-350 元/天 | 特色餐厅 + 1-2 顿名店（如平遥家宴） |
| 交通 | 250-400 元/天 | 高铁 + 区域包车（雁北段） |
| 门票 | 500-800 元 | 含云冈、平遥联票、五台山进山、悬空寺等 |
| 可行路线 | 雁北 5 日主线 | 大同 + 云冈 + 应县 + 悬空寺 + 五台 |

**要点**：**山西 5 日线的标准预算**。这档能走完雁北古建金三角 + 五台，包车不心疼。注意五台山、恒山海拔高，备外套。

### 档位 5｜人均 5000 元（深度品质 · 5-7 天）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 800-1200 元/晚 | 古城高端客栈、景区品质酒店 |
| 餐饮 | 400-550 元/天 | 好餐厅为主，含面食宴/晋商宴 |
| 交通 | 400-700 元/天 | 全程包车 + 高铁衔接 |
| 门票 | 800 元以上 | 全含，含缆车、讲解、VIP 通道 |
| 可行路线 | 7 日全省环线（晋中 + 雁北） | 太原 + 平遥 + 大院 + 大同 + 应县 + 悬空寺 + 五台 |

**要点**：到这一档可走「晋中 + 雁北」双板块并加入壶口或太行（二选一）。全程包车让古建串联不再受公交班次约束。

### 档位 6｜人均 8000 元（高端精品 · 7 天）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 1500-2500 元/晚 | 平遥/大同精品古建酒店、五台高品质民宿 |
| 餐饮 | 600-800 元/天 | 高端晋菜、定制面食宴 |
| 交通 | 700 元/天 | 专车 + 司机，机场接送 |
| 门票体验 | 不限 | 含私享讲解、古建专家导览 |

**要点**：山西的高端在于「住进历史」——平遥明清院落、大同古城墙畔精品酒店，体验不可替代。

### 档位 7｜人均 10000 元以上（奢华定制）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 3000 元/晚以上 | 顶奢古建套房、私享院落 |
| 餐饮 | 1000 元/天以上 | 主厨定制、包场晋商宴 |
| 交通 | 不限 | 豪华专车、商务接待 |
| 特色体验 | 不限 | 古建专家私导、五台晨钟专场、壁画临摹体验 |

**要点**：这一档买的是「时间与视角」——例如云冈避开人潮的私享讲解时段、五台山清晨空寺，普通游客难以获得。

## 人数适配说明

山西的**包车成本**使人数成为影响人均预算的关键变量，雁北、壶口、太行线尤为明显。

### 1 人出行

- **住宿**：青旅床位（60-120 元）或经济连锁单间（150-250 元）最经济。
- **交通**：**包车极不划算**（一人承担全车费）。建议：① 高铁 + 公交完成城际；② 在正规平台拼车游雁北/壶口；③ 参加一日游团。
- **餐饮**：面食、小吃为主，点菜型餐厅不友好（晋菜份量大）。山西面食丰富，单人反而吃得灵活。
- **安全提示**：五台朝台、太行徒步、野长城等**不要独自走未开发路线**，结伴或请向导。
- **适合路线**：太原晋祠 + 博物院、平遥古城、大同市区（云冈可拼车）。

### 2 人出行 ★

- **住宿**：性价比最优，标准间/大床房均摊后品质预算减半。
- **交通**：可以拼车，人均摊薄。雁北（云冈—应县—悬空寺）两人均摊包车（约 300-400 元/天）比各自坐车更自由。
- **餐饮**：可以点 3-4 个菜，过油肉、平遥牛肉都能尝。
- **适合路线**：全部路线，默认推荐配置。

### 3 人出行

- **住宿**：**麻烦点**。山西古城/景区酒店多为标间/大床房，三人间少。方案：① 家庭房（提前确认）；② 加床（常加价 50-100 元）；③ 大床 + 单间；④ **民宿三居**（平遥、大同很多，三居 400-800 元/晚，人均最低）。
- **交通**：包车开始明显划算，三人均摊接近公共交通成本。
- **提示**：山西古城民宿多，**3 人强烈建议直接订整套民宿**。

### 4 人出行 ★

- **住宿**：两间标间，或整套两居/三居民宿。
- **交通**：**山西最适合的人数**——一辆轿车/SUV 刚好坐 4 人，包车费用最低档（400-700 元/天），人均 100-175 元/天，比任何公共交通组合都自由。
- **餐饮**：最理想点菜规模。
- **建议**：4 人包车走雁北（云冈—应县—悬空寺—五台），人均成本最优，强烈推荐。

### 5 人出行

- **住宿**：两间房（三人间 + 标间）或整套民宿。5 人以上直接找「可住 5-6 人」的民宿。
- **交通**：需 **7 座商务车**（约 600-900 元/天），人均 120-180 元/天，仍比 1-2 人包车划算。
- **餐饮**：可订桌吃正式的晋商宴、平遥牛肉宴。
- **提示**：5 人是「包车 + 整租」的性价比拐点。

### 10 人出行

- **住宿**：**整栋民宿/古院最划算**。平遥、大同、五台有大量可住 10-15 人的院落，整租约 1500-3000 元/晚，人均 150-300 元。
- **交通**：**包中巴（19 座）约 1000-1500 元/天**，人均 100-150 元/天，最优。
- **门票**：10 人以上可询问团体票（部分景区支持）；云冈、悬空寺登临、五台山需按人预约，团体统一操作。
- **组织建议**：山西景点分散、车程长，10 人务必提前确认集合时间地点。五台山/恒山海拔高，关注队内是否有不适者，按最弱者节奏走。
- **注意**：平遥、五台暑期与佛教节日住宿极紧，至少提前 2-3 周；悬空寺登临限流，团体需统一预约。

## 预算与人数组合速查

| 人数 \ 预算 | 500 | 1000 | 2000 | 3000 | 5000 | 8000 | 10000 |
|---|---|---|---|---|---|---|---|
| **1 人** | 青旅床位 + 平遥 | 青旅单间 + 高铁 | 经济单间 + 拼车 | 品质单间 + 一日游 | 古建酒店 | 高端客栈 | 顶奢套房 |
| **2 人** | 床位 ×2 | 经济标间 | 中端客栈（舒适） | 四星 + 区域包车 | 高端古院 | 古城精品 | 私人院落 |
| **3 人** | 青旅三人间 | 整套民宿 | 三居民宿 + 拼车 | 品质民宿 + 包车 | 高端整租 | 古建套间 | 顶奢别墅 |
| **4 人** | 两间青旅 | 整套民宿 | 四居民宿 + 包车 | 品质民宿 + 全程包车 | 高端整租 | 古建度假 | 私人院落 |
| **5 人** | 整租民宿 | 整租 + 拼车 | 整租 + 7 座 | 品质整租 + 7 座 | 高端整租 | 古建多间 | 别墅整栋 |
| **10 人** | 整栋院落 | 整栋 + 中巴 | 整栋 + 中巴 | 品质整栋 + 中巴 | 高端整栋 | 古建包院 | 私人庄园 |

> 表中「500 / 1000 / …」指人均预算档位（元）。山西的组合规律：**古建分散 + 必须包车，人数越多「包车 + 整租」优势越明显**；1-2 人去雁北/壶口/太行优先拼车或一日游团，避免独自承担车费。
