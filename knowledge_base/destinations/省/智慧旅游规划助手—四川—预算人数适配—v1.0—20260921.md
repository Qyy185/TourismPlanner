# 四川预算与人数适配

本文件是四川目的地的「参数层」，回答两个问题：同样的路线，**不同预算**怎么调整？**不同人数**有什么差异？

---

## 四川的成本特征（先看这个）

四川的预算结构有两个关键点必须先理解：

1. **成都平原便宜、川西高原贵**。成都地铁 + 高铁出行成本低，住宿餐饮中等；九寨、稻城、四姑娘山等高原目的地，因路途远、包车与机票占比高，人均成本明显抬升。同一路线，平原段与高原段可差 1 倍以上。
2. **包车是高原线最大的弹性支出**。去九寨、稻城、四姑娘山多依赖包车（成都出发环线 600-1000 元/天）或长途车。包车按车计价，**人数越多人均越低**——这是四川预算优化最大的杠杆。

**计算口径**：金额为人均人民币；**含**省内住宿、餐饮、城际交通、市内交通、门票娱乐；**不含**往返四川的大交通与旅游保险。

## 预算档位对照表

### 档位 1｜人均 500 元（极限穷游 · 1-2 天）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 50-80 元/晚 | 成都青旅多人间床位 |
| 餐饮 | 40-60 元/天 | 小吃、面馆、串串为主 |
| 交通 | 20-40 元/天 | 地铁 + 步行，不包车 |
| 门票 | 0-55 元 | 只走免费区：宽窄巷子、锦里、人民公园；熊猫基地 55 元 |
| 可行范围 | 成都单城 1-2 天 | 纯市区，不走高原 |

**要点**：四川穷游**只建议放在成都**——地铁便宜、免费景点多、小吃管饱。高原线光往返车费就超这档。

### 档位 2｜人均 1000 元（经济自助 · 2-3 天）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 100-180 元/晚 | 青旅单间或经济型酒店 |
| 餐饮 | 80-120 元/天 | 本地小馆 + 1 顿火锅 |
| 交通 | 80-150 元/天 | 城际列车（成都—都江堰/乐山）+ 市内公交 |
| 门票 | 100-200 元 | 选 1-2 个付费景点（熊猫基地 + 武侯祠） |
| 可行范围 | 成都 + 都江堰 3 天 | 走 3 日主线精简版 |

**要点**：城际列车提前买，成都—都江堰二等座约 15 元、成都—乐山约 50 元，临时买易无座。

### 档位 3｜人均 2000 元（舒适自助 · 3 天）★

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 200-350 元/晚 | 中端酒店或精品民宿 |
| 餐饮 | 130-180 元/天 | 口碑餐厅 + 1-2 顿火锅 |
| 交通 | 150-250 元/天 | 高铁衔接 + 偶尔打车 |
| 门票 | 200-350 元 | 含熊猫基地、武侯祠、都江堰等 |
| 可行范围 | 成都 + 都江堰青城山，或成都 + 乐山峨眉 3 天 | |

**要点**：**短假期的舒适区间**。3 天建议只走「成都 + 近郊（都江堰/乐山）」，高铁 1 小时圈，节奏刚好。成都住春熙路/太古里一带出行最省心。

### 档位 4｜人均 3000 元（品质游 · 5 天）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 400-700 元/晚 | 精品酒店、民宿 |
| 餐饮 | 250-350 元/天 | 特色餐厅 + 名店火锅 |
| 交通 | 250-400 元/天 | 高铁 + 近郊打车，部分包车 |
| 门票 | 400-600 元 | 含峨眉山（索道）、乐山大佛等 |
| 可行范围 | 成都—乐山—峨眉 5 日主线 | |

**要点**：**四川 5 日平原线的标准预算**。这一档能走完整的「成都 + 乐山峨眉」，住得舒服、吃得好。峨眉山金顶索道 + 观光车约 110 元要预留。

### 档位 5｜人均 5000 元（深度品质 · 5-7 天）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 800-1200 元/晚 | 高端酒店、度假村 |
| 餐饮 | 400-550 元/天 | 好餐厅为主 |
| 交通 | 400-700 元/天 | 包车 + 省内机票（如九黄机场进出） |
| 门票 | 600 元以上 | 全含，含高原景区 |
| 可行范围 | 成都 + 九寨黄龙 7 日线 | |

**要点**：到这一档可用「机票换时间」——成都飞九黄机场（约 1 小时）替代 8-9 小时长途车，省下的时间留给景区。九寨沟口住宿旺季贵，提前订。

### 档位 6｜人均 8000 元（高端精品 · 7 天）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 1500-2500 元/晚 | 九寨沟高端度假村、成都奢华酒店 |
| 餐饮 | 600-800 元/天 | 高端餐厅、定制餐 |
| 交通 | 700 元/天 | 专车 + 司机，机场接送 |
| 门票体验 | 不限 | 含 VIP 通道、私享导览 |

**要点**：四川高端住宿的独特性在于九寨沟度假村与成都太古里奢华酒店，高原段的舒适房型能有效缓解高反。

### 档位 7｜人均 10000 元以上（奢华定制）

| 项目 | 标准 | 说明 |
|---|---|---|
| 住宿 | 3000 元/晚以上 | 顶奢度假村套房、私人院落 |
| 餐饮 | 1000 元/天以上 | 主厨定制、包场 |
| 交通 | 不限 | 豪华专车 + 直升机（如稻城亚丁空中航线） |
| 特色体验 | 不限 | 私人向导、贡嘎/亚丁日出专车、藏文化探访 |

**要点**：这一档买的是「时间与视角」——例如稻城亚丁的牛奶海在好天气下的光影、九寨沟避开人潮的私享时段，私人向导能大幅提高体验。

## 人数适配说明

四川的**包车成本**使人数成为影响人均预算的关键变量，高原线尤其明显。

### 1 人出行

- **住宿**：青旅床位（50-100 元）或单间（120-200 元）最经济。中端酒店按间计价，独行成本高。
- **交通**：**高原线包车不划算**（一人承担全车费）。建议：① 参加正规一日游/小团；② 靠高铁 + 长途车完成移动；③ 在平台拼车。
- **餐饮**：小吃、面馆、单人火锅灵活，点菜型餐厅不友好。
- **安全提示**：徒步线路（四姑娘山、达古冰川周边）**不要独自走**，务必结伴或请向导。
- **适合路线**：成都单城、成都 + 都江堰、美食探店线。

### 2 人出行 ★

- **住宿**：性价比最优。标准间/大床房均摊后，同样品质预算减半。
- **交通**：可拼车，人均摊薄。成都—乐山高铁二等座两人约 100 元往返，比各自打车划算。
- **餐饮**：可点 3-4 个菜，火锅、跷脚牛肉都能尝。
- **适合路线**：全部路线，默认推荐配置。

### 3 人出行

- **住宿**：**麻烦点**。酒店多为标间/大床房，三人间少。方案：① 家庭房（提前确认）；② 加床（常加价 50-100 元）；③ **民宿三居**（成都、都江堰很多，三居 400-700 元/晚，人均最低）。
- **交通**：包车开始明显划算，三人均摊后接近公共交通成本。
- **提示**：四川民宿丰富，**3 人强烈建议整租民宿**，比订酒店房间便宜且舒适。

### 4 人出行 ★

- **住宿**：两间标间，或整套两居/三居民宿。
- **交通**：**最适合的人数**——一辆轿车/SUV 刚好坐 4 人，包车费用最低档。高原环线（九寨、稻城）4 人包车人均成本最优。
- **餐饮**：最理想的点菜规模。
- **建议**：4 人包车（约 600-900 元/天）人均 150-225 元/天，比任何公共交通组合都自由。

### 5 人出行

- **住宿**：两间房（三人间 + 标间）或整套民宿。5 人以上建议找「可住 5-6 人」的民宿。
- **交通**：需 **7 座商务车**（约 800-1000 元/天），人均 160-200 元/天，仍比 1-2 人包车划算。
- **餐饮**：可订桌吃正式火锅与川菜宴。
- **提示**：5 人是「包车 + 整租」的性价比拐点。

### 10 人出行

- **住宿**：**整栋民宿/小院最划算**。都江堰、成都周边有大量可住 10-15 人的院落，整租约 1500-3000 元/晚，人均 150-300 元。
- **交通**：**包中巴（19 座）约 1000-1500 元/天**，人均 100-150 元/天，最优。
- **门票**：10 人以上可询问团体票政策（部分景区支持）。
- **组织建议**：高原目的地（九寨、稻城）车程长，10 人务必提前确认集合时间。高海拔段关注队内是否有身体不适者，不按最强者节奏走。
- **注意**：九寨沟观光车、黄龙索道等按人预约，10 人需统一提前抢票，建议留备选方案。

## 预算与人数组合速查

| 人数 \ 预算 | 500 | 1000 | 2000 | 3000 | 5000 | 8000 | 10000 |
|---|---|---|---|---|---|---|---|
| **1 人** | 青旅床位 + 免费区 | 青旅单间 + 高铁 | 客栈单间 + 动车 | 精品单间 + 一日游 | 高端酒店 + 拼车 | 度假酒店 | 顶奢套房 |
| **2 人** | 床位 ×2 | 经济酒店标间 | 中端酒店 + 高铁 | 品质酒店 + 近郊 | 高端民宿 | 奢华酒店 | 私人院落 |
| **3 人** | 青旅三人间 | 整套民宿 | 三居民宿 + 拼车 | 品质民宿 + 包车 | 高端整租 | 度假村套间 | 顶奢别墅 |
| **4 人** | 两间青旅 | 整套民宿 | 四居 + 包车 | 品质民宿 + 全程包车 | 高端整租 | 度假村 | 私人院落 |
| **5 人** | 整租民宿 | 整租 + 拼车 | 整租 + 7 座 | 品质整租 + 7 座 | 高端整租 | 度假村多间 | 别墅整栋 |
| **10 人** | 整栋院落 | 整栋 + 中巴 | 整栋 + 中巴 | 品质整栋 + 中巴 | 高端整栋 | 度假村包区 | 私人庄园 |

> 表中「500 / 1000 / …」指人均预算档位（元）。四川的组合规律是：**人数越多，「包车 + 整租」优势越明显，且高原线（九寨/稻城）比平原线更依赖人数摊薄**；1-2 人走高原线应偏向「高铁/飞机 + 拼车/小团」，避免独自承担车费。
