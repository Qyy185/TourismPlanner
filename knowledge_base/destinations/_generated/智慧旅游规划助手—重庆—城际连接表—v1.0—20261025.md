# 重庆 · 城际连接表

> 本文件记录本省各城市之间、以及本省与邻省之间的**城际交通连接**：距离、时长、方式、票价。
> 三份配套文件各管一件事：
> - 「{省}—城市总览」讲**在这座城玩什么**；
> - 本文件讲**怎么从这座城到下一座城**；
> - 「{省}—跨城路线」讲**按几天分配、怎么串成一条线**。
> 
> **数据口径**：距离为球面直线距离乘以铁路绕行系数 1.27（全国均值）；
> 铁路可达性依据真实高铁干线（见 core/rail_network.py），
> 标注「直达 / 需换乘 / 需公路接驳」；时长含中转与接驳余量；
> 票价为二等座 / 客车 / 经济舱参考价，以实际购票为准。
