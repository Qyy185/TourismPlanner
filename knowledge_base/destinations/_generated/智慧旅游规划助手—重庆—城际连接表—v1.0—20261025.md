# 重庆 · 城际连接表

> 本文件记录本省各城市之间、以及本省与邻省之间的**城际交通连接**：距离、时长、方式、票价。
> 三份配套文件各管一件事：
> - 「重庆—城市总览」讲**在这座城玩什么**；
> - 本文件讲**怎么从这座城到下一座城**；
> - 「重庆—跨城路线」讲**按几天分配、怎么串成一条线**。
> 
> **数据口径**：
> - 距离：球面直线距离 × 1.27（铁路绕行系数）；近程公路另按 1.25 折算；
> - 铁路可达性：依据真实高铁干线（见 `core/rail_network.py`），
>   标注「直达 / 需换乘 / 需公路接驳」；
> - 时长：含中转换乘余量与两端公路接驳段；
> - 票价：二等座 / 客车 / 经济舱参考价，**以实际购票为准**。
