# 江苏 · 城市总览

> 本文件由省级主攻略按城市下沉生成，保留原始景点字段（门票 / 开放时间 / 建议游玩 / 交通 / 实用建议）。

## 全省概览

- **最佳旅行季节**：3-5 月（春花、不冷不热）、9-11 月（秋高气爽、桂花季）。避开 6 月下旬—7 月上旬梅雨、7-8 月盛夏高温（35℃+）
- **建议游玩天数**：单城 2-3 天；南京 + 苏州 4-5 天；宁苏锡扬 + 镇江 6-8 天
- **人均预算参考**：2500-4500 元（5 天，不含往返大交通）。江浙沪高铁密集，城际成本低
- **行政区类别**：省
- **省会**：南京
- **主要旅行城市**：南京、苏州、无锡、扬州、镇江、常州、连云港
- **关键词**：古典园林、水乡古镇、秦淮风光、太湖、瘦西湖、早茶

## 南京

### 中山陵（南京）

孙中山先生陵寝，位于南京钟山风景区，392 级台阶逐级升高至祭堂，建筑为吕彦直设计的蓝白基调中西合璧风格，气势庄严。

- **门票**：免费（需提前在官方公众号预约）；景区内观光车另计
- **开放时间**：8:30—17:00（周一闭馆，法定节假日除外）
- **建议游玩**：2—3 小时（含音乐台、美龄宫可加）
- **交通**：南京地铁 2 号线「苜蓿园」站，或公交至「中山陵」站
- **实用建议**：**必须提前预约**，旺季限流。台阶多，老人量力。可与明孝陵、音乐台、美龄宫串成钟山一日。夏季遮阴少，带伞防晒。

### 明孝陵（南京）

明太祖朱元璋与马皇后合葬陵，明初三号陵寝，神道（石象路）两侧立石兽石人，秋季石象路银杏金黄极美。2003 年作为明清皇家陵寝扩展入选世界遗产。

- **门票**：约 70 元（与美龄宫、音乐台等可买联票）；以官方为准
- **开放时间**：6:30—18:00（夏季延长）
- **建议游玩**：2—3 小时
- **交通**：地铁 2 号线「苜蓿园」站步行；或从中山陵步行抵达
- **实用提示**：石象路是摄影名点，**秋天（11 月）银杏金黄**最出片。梅花山（明孝陵范围内）3 月梅花节热闹。与中山陵相邻，可同天游览。

### 夫子庙—秦淮风光带（南京）

以夫子庙为核心、秦淮河为轴线的历史文化街区，含江南贡院、乌衣巷、李香君故居等。夜游秦淮画舫是经典项目。

- **门票**：街区免费；江南贡院约 50 元、画舫约 80-100 元；以官方为准
- **开放时间**：街区全天；画舫约 9:00—22:00
- **建议游玩**：半天至 1 天
- **交通**：地铁 3 号线「夫子庙」站
- **实用建议**：**夜游画舫比白天更有味道**。街区商业化重、小吃溢价高，想吃地道去老门东（步行 10 分钟），鸡鸣汤包、小郑酥烧饼更本地。节假日人极多，错峰。

### 南京总统府（南京）

近代中国重要遗址，太平天国天王府、民国国民政府所在地，中国近代史实物展陈丰富，建筑融合中西。

- **门票**：约 35 元（旺季 40 元）；以官方为准
- **开放时间**：8:30—18:00（周一闭馆）
- **建议游玩**：2—3 小时
- **交通**：地铁 2 / 3 号线「大行宫」站
- **实用提示**：需预约，建议早去避开团队。西侧煦园（江南园林）值得一看。与1912 街区相邻，晚上可逛。

## 苏州

### 拙政园（苏州）

中国四大名园之首，苏州古典园林代表作，明代兴建，以水为中心、亭台廊榭借景布局，1997 年列入世界文化遗产。

- **门票**：淡季约 70 元、旺季约 90 元；以官方为准
- **开放时间**：7:30—17:30（冬季略短）
- **建议游玩**：2—3 小时
- **交通**：苏州地铁 4 号线「北寺塔」站步行，或公交至「拙政园」站
- **实用建议**：**旺季人挤人，务必早开园即入或预约分时段**。可与隔壁苏州博物馆（贝聿铭设计，免费预约）、狮子林串成半日。园林讲究移步换景，别走马观花。

### 平江路历史街区（苏州）

苏州保存最完整的古街区，沿平江河展开，河街并行、小桥流水，两侧是评弹馆、手作店、小吃。是苏州「慢生活」的代表。

- **门票**：免费
- **开放时间**：全天（店铺约 9:00—21:00）
- **建议游玩**：2—3 小时
- **交通**：地铁 1 号线「相门」站步行；拙政园打车约 10 分钟
- **实用建议**：比观前街安静地道。可听一场评弹（伏羲会馆等），吃鸡脚旮旯、桃花源记等位小吃。清晨人少最有水乡味。

### 周庄古镇（苏州昆山）

中国最著名的水乡古镇之一，「中国第一水乡」，双桥、沈厅、张厅是标志，明清民居临河而建。

- **门票**：约 100 元（日游联票，含主要宅院）；夜游 / 晨游部分时段免费政策以官方为准
- **开放时间**：景区全天，宅院约 8:00—17:00
- **建议游玩**：半天至 1 天
- **交通**：苏州 / 上海乘大巴或自驾约 1—1.5 小时；昆山南站转公交
- **实用建议**：**早上开园前或傍晚后**人少、可拍空巷；日游票含沈厅张厅。商业化重，想清静住一晚看夜景。

### 同里古镇（苏州吴江）

退思园（世界文化遗产）所在地，水乡格局完整，区别于周庄的是更生活化、少些喧嚣。

- **门票**：约 100 元（联票含退思园等）；以官方为准
- **开放时间**：全天（宅园约 8:00—17:00）
- **建议游玩**：半天
- **交通**：苏州自驾 / 公交约 1 小时；吴江转车
- **实用提示**：退思园是江南园林小巧精品，必看。相比周庄更本地，适合慢逛。可和周庄二选一，或同里 + 甪直组合。

## 无锡

### 鼋头渚（无锡）

太湖西北岸半岛，以「太湖第一名胜」著称，樱花谷（3 月樱花节）闻名，可乘船游太湖、看烟波浩渺。

- **门票**：约 90 元（樱花节期间上浮）；以官方为准
- **开放时间**：8:00—17:30
- **建议游玩**：半天
- **交通**：无锡市区公交 / 打车约 40 分钟；或环太湖线
- **实用提示**：**3 月下旬樱花节**是人气巅峰，需预约且人多；非花季反而清净。乘船去太湖仙岛需另购票。夏季湖风大，带薄外套。

### 灵山大佛（无锡）

高达 88 米的青铜释迦立佛，位于马山半岛，含灵山梵宫（奢华佛教艺术宫殿）、九龙灌浴表演，是华东著名佛教文化景区。

- **门票**：约 210 元；以官方为准
- **开放时间**：7:00—17:30（梵宫时间略短）
- **建议游玩**：半天
- **交通**：无锡市区乘公交 88 / 89 路约 1 小时，或打车 / 包车
- **实用提示**：梵宫内部金碧辉煌值得细看；九龙灌浴有固定表演时段，提前查好。景区大，穿舒适鞋。可与鼋头渚分两天或同在天目湖 / 马山一线。

## 扬州

### 瘦西湖（扬州）

扬州标志性湖上园林，因湖面瘦长得名，五亭桥、白塔、二十四桥是经典意象，「烟花三月下扬州」即指此处。

- **门票**：淡季约 60 元、旺季约 100 元；以官方为准
- **开放时间**：6:30—17:30（夜游另计）
- **建议游玩**：2—3 小时
- **交通**：扬州市区公交 / 打车约 20 分钟；或骑行
- **实用提示**：**春季（3-4 月）琼花、桃花季最美**。可坐船游湖。夜游瘦西湖灯光秀另购票。与个园、何园可串成扬州一日。

## 镇江

### 镇江金山·西津渡（镇江）

金山寺因「白娘子水漫金山」传说闻名，依山而建的寺塔一体；西津渡是千年渡口古街，保留了镇江最完整的明清—民国街区。

- **门票**：金山约 65 元；西津渡街区免费；以官方为准
- **开放时间**：8:00—17:00（西津渡全天）
- **建议游玩**：半天（两处可同游）
- **交通**：镇江站打车约 15 分钟；或高铁镇江站转公交
- **实用提示**：西津渡比金山更值得慢逛，古街 + 英租界旧址 + 锅盖面。镇江紧邻扬州，可宁镇扬一线串玩。

## 常州

### 常州中华恐龙园（常州）

以恐龙主题为核心的综合性乐园，含恐龙谷温泉、游乐园与恐龙馆，适合亲子，有「东方侏罗纪」之称。

- **门票**：约 230—260 元；以官方为准
- **开放时间**：9:00—17:00（暑期夜场延长）
- **建议游玩**：1 天
- **交通**：常州地铁 / 公交直达；或高铁常州站转乘
- **实用提示**：亲子首选，项目排队久，建议开园即入或购快速通行。夏季有水上项目。与春秋淹城乐园可二选一。

## 连云港

### 花果山（连云港）

《西游记》文化名山，江苏最高峰玉女峰（约 624 米）所在地，山上有水帘洞、三元宫等景点，林木葱郁。

- **门票**：约 90 元（景交车另计）；以官方为准
- **开放时间**：7:30—17:00
- **建议游玩**：半天至 1 天
- **交通**：连云港市区 / 高铁站打车或公交约 40 分钟
- **实用提示**：水帘洞是打卡点，玉女峰可远眺黄海。山间台阶多，夏季注意防暑补水。连云港离苏南较远，通常作为苏北单独一线。

## 全省 · 特色美食

### 南京

- **盐水鸭**——南京招牌，皮白肉嫩，桂花鸭（秋季）最佳
- **鸭血粉丝汤**——街头早点，粉丝 + 鸭血鸭肠
- **皮肚面 / 大肉面**——南京面馆特色
- **汤包**——鸡鸣汤包、老字号蟹黄汤包（秋季）
- **梅花糕**——老门东小吃

### 苏州

- **苏式面**——枫镇大肉面、焖肉面，讲究汤头与面身
- **松鼠桂鱼**——苏帮名菜，外酥里嫩
- **蟹壳黄 / 鲜肉月饼**——秋季排队
- **糕团**——桂花糕、薄荷糕，甜食精致
- **碧螺春**——苏州洞庭东山特产绿茶

### 无锡

- **酱排骨（无锡肉骨头）**——甜口浓油，老字号三凤桥
- **小笼包**——无锡小笼偏甜，皮薄汁多
- **太湖三白**——白鱼、白虾、银鱼，清淡鲜美
- **油面筋**——无锡特色素菜

### 扬州

- **早茶**——富春 / 冶春的蟹黄汤包、三丁包、千层油糕、翡翠烧卖，「皮包水」文化
- **狮子头**——清炖蟹粉狮子头，大而嫩
- **大煮干丝**——淮扬刀工菜
- **扬州炒饭**——正宗版配料丰富

### 镇江 / 常州

- **镇江锅盖面**——面条筋道，地方一绝
- **肴肉**——镇江冷盘，配姜丝醋
- **常州银丝面**——细如银丝

**觅食提示**：江苏菜系（淮扬 / 苏帮 / 金陵）整体偏甜鲜、刀工精细。扬州早茶需**早起排队**（富春、冶春高峰 7-9 点），建议 6:30 前到。夏季梅雨闷热，注意饮食卫生，生冷适量。

## 全省 · 住宿建议

### 南京

- **新街口 / 夫子庙周边**：交通餐饮方便，中端 300—550 元 / 晚
- **钟山风景区附近**：安静，适合深度游，400—700 元 / 晚
- **老门东**：文艺民宿集中，300—600 元 / 晚

### 苏州

- **平江路 / 观前街**：古韵方便，民宿 300—600 元 / 晚
- **金鸡湖东岸**：现代商圈，高端酒店 600—1200 元 / 晚
- **同里 / 周庄内**：住一晚看夜景，400—800 元 / 晚

### 无锡 / 扬州

- **无锡太湖边**：度假酒店 500—1000 元 / 晚
- **扬州瘦西湖 / 文昌阁**：中端 300—600 元 / 晚，早茶方便

### 镇江 / 常州 / 连云港

- 市区经济型 200—450 元 / 晚；常州恐龙园周边亲子酒店 400—800 元 / 晚。

## 全省 · 交通指南

### 大交通

- **高铁 / 动车**：江苏是全国高铁最密省份之一。南京是枢纽（京沪 + 沪宁）；苏州、无锡、常州、镇江均在沪宁城际沿线，南京—苏州约 1.5 小时、上海—苏州约 25 分钟。扬州通过连镇铁路 / 宁启铁路联通。
- **航空**：南京禄口国际机场为主；苏南硕放（无锡 / 苏州共用）、扬州泰州机场为支线。
- **公路**：省内高速网极发达，沪宁、宁杭、盐靖等，自驾便利。

### 省内交通

- **城际**：优先高铁 / 动车，宁镇扬、苏锡常同城化明显，班次密集。
- **市内**：南京 / 苏州地铁覆盖主城；扬州、镇江、常州、连云港以公交 + 打车为主。
- **水乡接驳**：周庄、同里从苏州 / 上海有旅游专线大巴，自驾约 1—1.5 小时。

## 全省注意事项

- **梅雨季（6 月下旬—7 月上旬）**：持续阴雨、高温高湿（体感闷热），户外园林水乡易踩湿滑青石板，**务必带防水鞋 / 折叠鞋套与雨具**。也是苔藓衣物发霉高发期，行李放干燥处。
- **盛夏高温**：7-8 月常 35℃+，园林与水乡遮阴少，防晒、补水、避开正午。
- **园林预约**：拙政园、苏州博物馆、中山陵等热门**必须提前官方预约分时段**，旺季现场常约满。
- **水乡防坑**：周庄同里内餐饮、游船、拍照多溢价，先问价再消费；「免费晨游」政策以景区当日公告为准。
- **早茶排队**：扬州富春 / 冶春早茶高峰极挤，建议 6:30 前到或错峰。
- **古镇住宿**：水乡内民宿隔音差、拖行李走石板路不便，带大件行李建议住镇外。
- **消费维权**：景区周边「低价团」「强制购物」风险低但仍有，保留票据，遇纠纷拨 12345。
